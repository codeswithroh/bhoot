Bhoot

In Hindi, bhoot means ghost. It also means the past.

Bhoot reads a repository's git history on your own laptop and finds both: the people who left but whose code still runs, and the files that lived and died. A local Gemma writes each of them a short remembrance. Then code checks every name, number, date and file in it against git, and throws away anything Gemma made up.

Raise your own

ollama pull gemma3:4b
git clone https://github.com/codeswithroh/bhoot && cd bhoot
node src/cli.ts /path/to/your/repo --out graveyard
open graveyard/index.html

Needs Node 22.6+ and Ollama. Your repository never leaves your machine: git does the reading, Gemma runs locally, and the page is one HTML file.

How it stays honest

  1. Git gives the facts. Who wrote which line (git blame), when people came and went, which files were deleted, by which commit, and what they said when they did it.
  2. Gemma writes the words. Two sentences, Día de los Muertos in spirit: warm, a little eerie, never mocking.
  3. Code checks the words. Every number has to be a fact about the thing it counts. Every year has to belong to the right event. Every name has to have done what the sentence says they did.
  4. One retry, then plain facts. If Gemma invents a detail twice, the stone just carries the dates.
